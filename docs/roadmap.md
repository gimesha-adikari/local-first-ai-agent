# Milestones

| Version | Scope |
| --- | --- |
| v0.0.1 | Cargo workspace, shared core, Tauri desktop, React, and CI |
| v0.0.2 | Offline GGUF inference, streaming, thinking modes, and CPU benchmarks |
| v0.0.3 | Persistent SQLite chat, multi-turn context budgeting, and offline desktop acceptance |

The v0.0.3 scope is single-user chat on Linux CPU. Tools, attachments, semantic
memory, cloud sync, GPU inference, and additional platforms are outside the
milestone.
